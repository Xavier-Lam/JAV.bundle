# Contributing to JAV.bundle

Thank you for your interest in improving JAV.bundle!

## Filing an Issue

When creating a new issue, please include the following information so we can investigate effectively:

1. **Plugin version** – the release tag you installed (e.g. `v1.0.0`).
2. **Latest log** – attach your Plex log file (or the relevant portion) to the issue.
   The log is located at:
   ```
   {Plex Media Server data directory}/Logs/PMS Plugin Logs/com.plexapp.agents.jav2.log
   ```
   See [Plex documentation](https://support.plex.tv/articles/202915258-where-is-the-plex-media-server-data-directory-located/) for your data directory location.
3. **Video information** – the video ID or search conditions that reproduce the problem.
4. **Problem description** – a clear explanation of what happened versus what you expected.

> **Important:** Do **NOT** upload explicit content such as screenshots of your library.

### Issue template

```
**Plugin version**: v?.?.?

**Log**: <drag & drop your log file here as an attachment>

**Video**: <video ID or search keyword>

**Description**:
<describe the problem>
```
